# Android: Домашнее кино

Локальные assets + собственные FamilyActivity/FamilyPlayerActivity. Стартового экрана стандартной Lampa в APK нет. Сборка использует закреплённую Gradle-основу LAMPA; `prepare.py` проверяет коммит и создаёт чистый проект только с исходниками Family Cinema.

`assets/family/` содержит интерфейс и SVG, `res/` — иконки/баннер, `tests/FamilyDeviceTest.kt` — Android-проверку настоящих событий касания, ClipboardManager, Back и продвижения времени в реальном EX-FS плеере. Проверка эмулятора запускается отдельно вручную и не равна проверке конкретного телевизора владельца.

`FAMILY_APP_KEY` передаётся из закрытого окружения сборки. Подпись берётся из прежних GitHub Secrets. Сборка с отсутствующим ключом останавливается; подмена на debug запрещена. Резервная копия — `../BACKUP_KEYSTORE_DO_NOT_LOSE/`, в Git не входит.
