# Family Cinema для Android и Android TV

Полная сборка использует оригинальные исходники [lampa-app/LAMPA](https://github.com/lampa-app/LAMPA/tree/28d7616f52d969abd6a93d8692b15a8525b36efc) как закреплённую зависимость. Скрипт `prepare.py` проверяет точный коммит, копирует базу и применяет все изменения. Скрытого скачивания «последней версии» при сборке нет.

Изменения: отдельный пакет `io.github.jeavnex.familycinema`, название Family Cinema, запуск собственного веб-клиента с семейным плагином, портретная и альбомная ориентация телефона, сохранённый TV launcher, отдельный экран сторонних плееров без доступа к AndroidJS. Встроенное обновление оригинальной Lampa отключено: обновления APK устанавливаются из этого репозитория.

В GitHub Actions всё выполняется автоматически. Локальная сборка для разработчика:

```text
python android-tv-mobile-app/prepare.py
cd android-tv-mobile-app/generated
./gradlew assembleLiteDebug
```

Нужны JDK 17, Android SDK 34 и доступ к Maven/Google/GitHub. APK будет в `app/build/outputs/apk/lite/debug/`. На Windows используйте `gradlew.bat`.

Первая сборка использует отладочную подпись Android и предназначена для личной проверки. Повторная облачная сборка без собственного постоянного ключа может потребовать удалить прежнюю установку, что удалит её локальное избранное. Для обновлений с сохранением данных предусмотрены секреты подписи в workflow; порядок описан в главной инструкции.

Работа сторонних плееров с пультом зависит от самих плееров. Наличие TV launcher не означает, что любой внешний видеосайт поддерживает пульт. Проверка на реальном телефоне и телевизоре обязательна.
