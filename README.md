# Домашнее кино / Family Lampa

Собственное Android-приложение для телефона и Android TV с каталогом EX-FS. По последнему решению владельца исходники и APK публикуются в GitHub; сайта для просмотра нет, GitHub Pages отключён.

- Скачать APK: https://github.com/jeavnex/ex-fs-lampa/releases/download/latest/FamilyCinema.apk
- Резервная постоянная загрузка: https://family-cinema-api.pvde.workers.dev/download/FamilyCinema.apk
- Версия: https://family-cinema-api.pvde.workers.dev/api/version
- Пошаговая установка: [ИНСТРУКЦИЯ_ПО_ШАГАМ.md](ИНСТРУКЦИЯ_ПО_ШАГАМ.md).
- Подтверждённые проверки и ограничения: [ПРОВЕРКИ.md](ПРОВЕРКИ.md).

## Устройство проекта

`android-tv-mobile-app/assets/family/` — собственный локальный интерфейс, стили, SVG и агент плеера.
`android-tv-mobile-app/overlay/` — Android-экран, плеер, обновление, ClipboardManager и диагностика.
`android-tv-mobile-app/res/` — иконки всех плотностей, адаптивные иконки и ТВ-баннер 320×180.
`backend-cf/src/index.js` — парсер, защищённый API, кэш, диагностика, обслуживание и хранилище APK.
`.github/workflows/` — подписанная сборка, проверки, ежедневное обслуживание. Публикации Pages нет.

## Сборка и публикация

Android build base LAMPA закреплён на коммите `28d7616f52d969abd6a93d8692b15a8525b36efc`. Его Gradle-основа используется для воспроизводимой сборки. Исходный экран Lampa, её веб-клиент, плагины, TMDB, торренты, ресиверы и службы в APK не включены. Единственная стартовая Activity — `FamilyActivity`; интерфейс находится в APK assets. Android 5.0+ с современным Android System WebView.

`build-apk.yml` берёт постоянный ключ из GitHub Secrets, проверяет сборку и lint, перезаписывает файл `FamilyCinema.apk` в релизе `latest` и загружает копию в D1 через отдельный ограниченный ключ публикации. Отладочной подписи в релизной цепочке нет. Тег latest указывает на исходники актуального релиза.

В Secrets нужны `FAMILY_KEYSTORE_BASE64`, `FAMILY_KEYSTORE_PASSWORD`, `FAMILY_KEY_ALIAS`, `FAMILY_KEY_PASSWORD`, `FAMILY_APP_KEY`, `FAMILY_RELEASE_KEY`, `FAMILY_MAINTENANCE_KEY`. Последние три также настроены как секреты только Worker `family-cinema-api`. Значения не публикуются в Git.

## API и бесплатное обслуживание

Только `/download/FamilyCinema.apk` и `/api/version` открыты без ключа. Каталог, поиск, фильтры, карточки, `/health` и `POST /api/logs` требуют `X-Family-App-Key`. Для загрузки APK используется отдельный `X-Family-Release-Key`, для ручного обслуживания — `X-Family-Maintenance-Key`. Заголовок приложения не является невынимаемым секретом: его можно извлечь из APK. Это защита от обычного открытия API, а не персональная авторизация устройств.

Используется только `family_cinema_db` (`dcc2f29e-5453-48cc-b617-e499e7bc8586`) и Worker `family-cinema-api`. `scripts/guard.js` блокирует команды, если конфигурация указывает на другой проект. Старые таблицы не удаляются.

Cron Cloudflare выполняется ежедневно в 04:17 UTC; Actions — 05:47 UTC. Проверяются главная, реальные ссылки меню, поиск и до 10 самых давно проверенных карточек из кэша за запуск. Подтверждённый резервный разбор карточек может заменить основной в `parser_config`. При неизвестном изменении сохраняется последняя рабочая конфигурация и записывается ошибка в `maintenance_runs`. Автоматически переписывать произвольно изменившийся сайт без проверки невозможно.

Видео идёт напрямую от плееров, через Worker проходит только каталог, логи и скачивание APK. D1 хранит актуальный APK и временные загрузки; старые загрузки удаляются после суток. APK ограничен 24 МиБ; кэш — 2000 записей, диагностика — 300 отчётов. Платные тарифы, R2 и платные бюджеты не включаются. При исчерпании общей бесплатной квоты сервис/сборка могут остановиться: бесконечные бесплатные ресурсы не обещаются.

Резервная копия ключа и пароли находятся локально в `BACKUP_KEYSTORE_DO_NOT_LOSE/`, папка исключена из Git и архивов исходников.
