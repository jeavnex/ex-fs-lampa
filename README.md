# Family Cinema

Семейный интерфейс EX-FS для Lampa, Android и Android TV.

**Начните с [ИНСТРУКЦИЯ_ПО_ШАГАМ.md](ИНСТРУКЦИЯ_ПО_ШАГАМ.md).**

- Репозиторий: https://github.com/jeavnex/ex-fs-lampa
- Страница проверки: https://jeavnex.github.io/ex-fs-lampa/
- Кинотеатр: https://jeavnex.github.io/ex-fs-lampa/lampa/
- Плагин: https://jeavnex.github.io/ex-fs-lampa/family_exfs_plugin.js
- API: https://family-cinema-api.pvde.workers.dev
- Worker: `family-cinema-api`; D1: `family_cinema_db`; привязка: `FAMILY_DB`.

Постоянная подпись Android настроена через зашифрованные GitHub Secrets. Закрытого ключа и паролей в исходниках нет. Подписанный APK собирается в workflow `Build FamilyCinema.apk`.

API получает общедоступные карточки EX-FS и ссылки на встроенные на странице HTTPS-плееры. Он не скачивает фильмы, не передаёт видеопоток через Cloudflare, не снимает защиту источника. Поиск, каталог и карточки сохраняются в новой D1, на устройстве — избранное и история открытых плееров. Кэш ограничен 2000 записями.

Оригинальные исходники Lampa закреплены по коммитам и автоматически загружаются при сборке. Каталог `android-tv-mobile-app/` содержит полную подготовку Android-сборки и собственный экран плеера, а не пустую папку. Установленный Android-клиент автоматически открывает семейный веб-интерфейс с GitHub Pages.

Тесты сервера: `cd backend-cf`, `npm ci`, `npm test`. Они используют локальную D1 и имитированные ответы внешнего сайта; не обращаются к старому проекту Cloudflare.

Доступность сторонних плееров, реклама и управление внутри них определяются их владельцами. APK требует проверки на конкретном телефоне и телевизоре. Статус выполненных проверок указан в [ПРОВЕРКИ.md](ПРОВЕРКИ.md).
