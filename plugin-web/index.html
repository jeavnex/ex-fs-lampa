    Добавить плагин в свою Lampa

    В Lampa откройте «Настройки» → «Расширения» → «Добавить плагин» и вставьте:

    https://jeavnex.github.io/ex-fs-lampa/family_exfs_plugin.js

    Название пункта «Расширения» в некоторых версиях Lampa — «Плагины». После добавления перезапустите Lampa и выберите «Семейный кинотеатр» в меню слева.

    Скачать APK: открыть сборки GitHub · Инструкция по шагам
