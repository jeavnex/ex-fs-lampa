Проверены: вертикальный свайп с изменением scrollTop, фокус от D-pad, открытие настроек, копирование полного текущего отчёта, возврат в каталог, возврат на главную и системное окно «Выйти из приложения?». После оптимизации избранное читается один раз на экран, без повторного обращения к Android для каждого постера.

Это инструментированная debug-сборка коммита 8a30512. После неё изменена только высота нативных кнопок плеера: 48 dp для удобного нажатия на телефоне; эта правка отдельно прошла релизную компиляцию и lint. Обычный интерфейс и проверенные действия не менялись. Автоматический установщик в ней отключён, чтобы системные окна установки не вмешивались в тест. Релиз собирается с прежней постоянной подписью; APK, сертификат и контрольная сумма проверены отдельно. Установка поверх прежнего приложения и микрофон пульта на реальном устройстве владельца не проверялись: владелец предпочёл установку по ссылке без USB.

## Что произошло с настоящим видео

В браузере текущей среды реальный плеер EX-FS HD показал фильм «Апгрейд»: readyState=4, длительность 5994.541 с, время дошло до 236.685 с. После проверки фильм остановлен и вкладка закрыта. Это фактическое воспроизведение, а не только найденная ссылка.

[Полный Android-тест плеера](https://github.com/jeavnex/ex-fs-lampa/actions/runs/40868846574) закончился ошибкой: в сети GitHub первый источник вернул HTTP 410, второй — 404, третий — проверку Cloudflare и затем 410. Независимый сетевой запрос Node из того же runner тоже получил 410 с обычным и Android User-Agent. Это подтверждает недоступность источника в той тестовой сети; успешный UI-тест не выдаётся за успешное видео. Проверка не скрыта и не помечена зелёной.

Auto-Fallback действительно перебрал плееры и сохранил отчёт в D1 (HTTP 201). Видеопоток оставлен стандартному сетевому стеку WebView, чтобы сохранялись его TLS, cookies, Range и поведение самого плеера. shouldInterceptRequest блокирует рекламные домены; initial loadUrl получает Referer http://ex-fs.net/. Защита сайта и DRM не обходятся.

Позиция доступного HTML-видео/API плеера сохраняется локально. Для EX-FS HD учитывается playlist.current и идентификатор серии; для других плееров — распознаваемые select. Неизвестная разметка стороннего плеера может ограничивать восстановление сезона/серии.
