## Автоматические проверки

Все **10 тестов сервера** прошли локально в Miniflare с локальной D1 и отдельно в GitHub Actions. Они проверяют связь с таблицей, разбор каталога и карточки, реальное сохранение в тестовую D1, повторное чтение кэша, пустой поиск, ошибку источника, устаревший кэш, изменение HTML, входные ссылки и параметры, методы HTTP и CORS.

В тестах ответы EX-FS имитируются; это отдельная проверка поведения кода. Дополнительно парсер проверен на загруженном настоящем HTML EX-FS: 30 фильмов, 30 сериалов, 30 мультфильмов, 2 результата поиска и карточка с четырьмя плеерами.

[Успешные проверки GitHub Actions](https://github.com/jeavnex/ex-fs-lampa/actions/runs/40778577950).

## Настоящий опубликованный API

| Запрос | Результат |
|---|---|
| `/health` | HTTP 200, `ok: true`, таблица D1 доступна |
| `/api/catalog?category=movies` | HTTP 200, 30 карточек, есть следующая страница |
| `/api/catalog?category=series` | HTTP 200, 30 карточек |
| `/api/catalog?category=cartoons` | HTTP 200, 30 карточек |
| `/api/search?q=Апгрейд` | HTTP 200, 2 результата |
| Карточка из настоящего каталога | HTTP 200, название, год и 4 адреса встроенных плееров |
| `/api/catalog?page=0` | Ожидаемый HTTP 400, понятное сообщение |

Эти запросы обращались к опубликованному Worker и настоящему EX-FS. Первые ответы имели признак `cache: miss`: это не демонстрационные данные из тестов.
