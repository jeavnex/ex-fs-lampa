# Ревизия Family Cinema: исходное состояние перед переделкой

Проверено 29.10.2026 по исходникам, предыдущим результатам сборки и сообщению владельца о проверке на телефоне. Успешная сборка и запуск в браузере не являются проверкой на телефоне или Android TV.

| № | Фактическое состояние исходной версии | Что требуется |
|---|---|---|
| 1 | Репозиторий публичный; Pages включён; Lampa загружается с Pages; ключа приложения нет | Отключить Pages, закрыть репозиторий, перенести интерфейс в APK, ограничить API |
| 2 | APK только в краткоживущем артефакте Actions; релиза latest и собственного автообновления нет | Постоянная загрузка через Worker и обновление с проверкой подписи/контрольной суммы |
| 3 | Надстройка над обычной Lampa; возврат в её экран возможен; реализованы только 3 раздела | Собственный маршрутный стек и все реальные разделы EX-FS |
| 4 | Использован Scroll Lampa; сенсорная прокрутка на телефоне не проверена, владелец сообщил о поломке | Нативная прокрутка WebView, отдельная навигация пультом и голосовой поиск |
| 5 | Найдены ссылки на iframe; нет обязательного Referer, автопереключения, позиции, сезона/серии или блокировки рекламы | Исправить экран плеера, состояние просмотра, переключение и диагностику |
| 6 | Собственная диагностика отсутствует; ClipboardManager не реализован | Версия сборки, локальные логи, отправка в D1, код и QR, нативное копирование |
| 7 | Cron и ежедневного workflow нет; таблицы parser_config/media_cache нет | Проверяемое обслуживание с резервными способами разбора и отчётом о неисправности |
| 8 | Один постоянный ключ и GitHub Secrets уже созданы; резервная копия в work/private-signing | Сохранить тот же ключ в BACKUP_KEYSTORE_DO_NOT_LOSE, не создавать новый |

## Границы проверок

Ключ, встроенный в APK, можно извлечь из APK. Заголовок закрывает обычное открытие API в браузере, но не заменяет авторизацию отдельных устройств. Публичными останутся только явно запрошенные адреса загрузки APK и номера версии.

Автоматическое обслуживание может применять только проверенные резервные селекторы и подтверждённые перенаправления источника. Оно не должно выдумывать новый сайт или сообщать об успешном ремонте, если данные не удалось проверить.

Этот файл фиксирует исходную ревизию. Фактически завершённые изменения и подтверждённые проверки будут отдельно отражены в отчёте новой сборки.
