# Установка «Домашнее кино»: по кнопкам

## 1. Скачать на телефон

1. Откройте браузер на телефоне.
2. Нажмите [скачать FamilyCinema.apk с GitHub](https://github.com/jeavnex/ex-fs-lampa/releases/download/latest/FamilyCinema.apk).
3. Если GitHub временно недоступен, нажмите [скачать через Cloudflare](https://family-cinema-api.pvde.workers.dev/download/FamilyCinema.apk). Файл тот же.
4. Дождитесь завершения скачивания. Откройте уведомление **«FamilyCinema.apk — скачивание завершено»**. Или откройте приложение **Файлы → Загрузки → FamilyCinema.apk**.
5. Если Android предложит разрешить установку из браузера: **Настройки → Разрешить из этого источника**, затем вернитесь назад.
6. Нажмите **Обновить** (если старая версия уже установлена) или **Установить**.
7. После установки нажмите **Открыть**. Значок приложения — золотая лампа, название — **Домашнее кино**.

Старую версию с постоянной подписью удалять не нужно. Если Android пишет «Приложение не установлено», сохраните точный текст ошибки: старая отладочная версия могла иметь другую подпись. Удаление приложения стирает его локальные данные, поэтому сначала выясните причину ошибки.

## 2. Установить на Android TV

Если у телевизора есть браузер: откройте ту же ссылку скачивания, затем файл в папке **Загрузки**. При запросе Android TV откройте **Настройки → Приложения → Специальный доступ → Установка неизвестных приложений**, разрешите установку вашему браузеру или файловому менеджеру и вернитесь к APK. Названия разделов могут отличаться у производителей.

Если браузера нет: скачайте APK на компьютере, скопируйте **FamilyCinema.apk** на USB-флешку, подключите её к телевизору и откройте файл установленным файловым менеджером. Плитка приложения в меню телевизора — широкая, с лампой и надписью «Домашнее кино».

## 3. Пользоваться

1. Выберите **Главная**, **Фильмы**, **Сериалы**, **Мультфильмы** или **Передачи и шоу**.
2. На телефоне прокручивайте ленты пальцем вбок, страницу — вверх/вниз. На ТВ используйте стрелки пульта и **ОК**. Фокус отмечен золотой рамкой.
3. Для поиска откройте **Поиск**, введите название и нажмите **Найти**. **Голос** запускает системный голосовой ввод; если его нет на устройстве, остаётся обычная клавиатура.
4. Откройте карточку, нажмите **Смотреть**. Можно выбрать конкретный плеер. Озвучки и серии выбираются в самом плеере, если они доступны для этого фильма.
5. Если плеер не подтверждает запуск за 35 секунд, приложение пробует следующий. Кнопка **Плеер** позволяет переключить вручную.
6. **Назад** над плеером или кнопка пульта закрывает видео. На главной **Назад** показывает вопрос о выходе.
7. Нажмите **В избранное**, чтобы сохранить карточку. **Продолжить** появляется после подтверждённого просмотра. Избранное, история и позиции находятся на каждом устройстве отдельно.

У разных встроенных плееров разные возможности. Позиция сохраняется при доступной телеметрии HTML-видео или API плеера; сезон/серия — при распознаваемых элементах выбора. Неизвестный сторонний плеер может требовать ручного выбора серии. Региональная блокировка источника или самого видео не устраняется успешной сборкой APK.

## 4. Обновления

При запуске приложение проверяет номер сборки. Новая версия скачивается автоматически, проверяется по SHA-256, имени пакета и подписи, после чего Android показывает своё окно **Обновить**. Один раз Android может попросить разрешить установку обновлений именно для «Домашнее кино». Подтвердите, если хотите получать обновления. Установка всегда требует системного подтверждения.

Ручная проверка: **значок шестерёнки справа вверху → Проверить обновление**. Номер и дата сборки показаны в шапке и настройках. Если установлена старая версия без обновлятора, скачайте новый APK по постоянной ссылке один раз.

## 5. Если что-то не работает

1. Нажмите **шестерёнку → Логи / Диагностика**. В плеере есть отдельная кнопка **Логи**.
2. Дождитесь сохранения отчёта. При доступном сервере появятся **четыре цифры** и QR с номером отчёта и сборкой.
3. Нажмите **Скопировать лог**. Это системный буфер обмена Android.
4. Вернитесь в этот чат, удерживайте палец в поле ввода и нажмите **Вставить**. Отправьте отчёт или напишите четыре цифры и номер сборки.
5. Если связи с сервером нет, полный текущий отчёт остаётся на устройстве, его можно скопировать. Вместо серверного кода будут прочерки: приложение не выдумывает успешную отправку.

Владелец может посмотреть сохранённый отчёт: Cloudflare → **Storage & databases → D1 → family_cinema_db → Console**. Запрос по коду, например: `SELECT code,version,payload FROM diagnostics_logs WHERE code='1234' ORDER BY created_at DESC LIMIT 5;`. Другая база аккаунта для этого не используется.

## 6. Выпустить следующую сборку без программирования

1. Откройте [репозиторий](https://github.com/jeavnex/ex-fs-lampa) под своим аккаунтом.
2. Нажмите **Actions**.
3. Слева выберите **Build FamilyCinema.apk**.
4. Нажмите **Run workflow → Run workflow**. Дождитесь зелёной галочки.
5. Постоянные ссылки обновятся сами. Имя файла всегда **FamilyCinema.apk**. Релиз — **latest**.

Если появилась красная ошибка, APK не считается готовым. Откройте запуск → **build** и сохраните текст ошибки. Не меняйте ключ подписи и не вставляйте пароли в чат.

## 7. Самое важное: сохранить ключ

В корне локальной папки репозитория есть **BACKUP_KEYSTORE_DO_NOT_LOSE**. Внутри — **keystore.jks** и **KEYSTORE_CREDENTIALS.txt**. Скопируйте всю папку на свою флешку или в закрытое хранилище. Не загружайте её в GitHub, публичный архив или чат. Без того же ключа нельзя выпустить совместимое обновление.

Сайт GitHub Pages не нужен и должен оставаться отключённым. По последнему решению владельца сам репозиторий публичный, чтобы APK скачивался с GitHub без входа.
