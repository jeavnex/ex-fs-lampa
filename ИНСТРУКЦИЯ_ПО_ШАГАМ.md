# Family Cinema: инструкция по шагам

Вы не должны самостоятельно писать код. Все файлы находятся в [вашем репозитории](https://github.com/jeavnex/ex-fs-lampa). Фактические результаты проверки опубликованы отдельно в [ПРОВЕРКИ.md](ПРОВЕРКИ.md): наличие файлов само по себе не означает успешную публикацию или сборку APK.

## 1. Сначала откройте кинотеатр в браузере

1. Нажмите: **https://jeavnex.github.io/ex-fs-lampa/**.
2. В блоке «Проверка сервера» дождитесь ответа. Нормальный результат: «Сервер и база работают. Получено фильмов: 30» (число может отличаться).
3. Нажмите большую кнопку **«Открыть семейный кинотеатр»**.
4. Дождитесь загрузки Lampa. Откроется раздел «Фильмы» семейного интерфейса. Если открылся обычный экран Lampa, в левом меню выберите **«Семейный кинотеатр»**.
5. Нажмите **«Найти фильм»**, введите название минимум из двух букв и нажмите **«Готово»**.
6. Выберите карточку. Нажмите **«Смотреть: Плеер EX-FS HD»** либо другую кнопку плеера. Воспроизведение запускается кнопкой внутри самого плеера; автоматического запуска со звуком браузер может не разрешить.
7. Для выхода используйте **«Закрыть плеер / Назад»**. Если плеер перехватил клавиатуру, щёлкните эту кнопку мышью или воспользуйтесь кнопкой браузера «Назад».
8. Если плеер не открывается внутри окна, нажмите **«Открыть отдельно»**. При блокировке сторонним сайтом откройте **«Открыть страницу EX-FS»** из карточки.

Списки «Избранное» и «История» находятся на устройстве, которым вы пользуетесь. Между телефоном, телевизором и браузером они не синхронизируются. «История» означает открытые плееры, а не подтверждённые просмотры; позицию просмотра стороннего плеера приложение не получает.

## 2. Скачать готовый APK

1. Войдите в GitHub в браузере. Для скачивания файлов из раздела Actions GitHub обычно требует вход.
2. Откройте **https://github.com/jeavnex/ex-fs-lampa/actions/workflows/build-apk.yml**.
3. Найдите последний запуск с **зелёной галочкой**. Красный крестик означает, что APK в этом запуске не собрался.
4. Щёлкните название успешного запуска.
5. Прокрутите страницу вниз до **Artifacts** («Артефакты»).
6. Нажмите **FamilyCinema**. Скачается ZIP-архив.
7. Откройте ZIP и извлеките **FamilyCinema.apk**. Именно этот файл устанавливают на Android.

Артефакты хранятся **1 день**, чтобы не расходовать лишнее место. Если файл уже недоступен: на странице из пункта 2 нажмите справа **Run workflow** → ещё раз зелёную **Run workflow**. Дождитесь успешного завершения и повторите пункты 3–7. Никакого платного сервера для сборки не нужно.

## 3. Установить на телефон

1. Передайте `FamilyCinema.apk` на телефон: через USB, личное облако или свой Telegram «Избранное».
2. Откройте приложение **«Файлы»** на телефоне, затем папку **Download / Загрузки** или ту папку, куда вы сохранили файл.
3. Нажмите **FamilyCinema.apk**.
4. Если Android просит разрешить установку из этого источника: нажмите **«Настройки»**, разрешите установку для того приложения, которым вы открыли APK, и вернитесь назад. Делайте это только для APK, скачанного из вашего репозитория.
5. Нажмите **«Установить»**, затем **«Открыть»**.
6. На первом запуске нужен интернет: приложение загружает интерфейс с вашего GitHub Pages. Семейный плагин подгружается автоматически.
7. Откройте фильм и плеер. В Android-сборке плеер открывается на отдельном экране, сверху есть **«Назад к фильму»**. Аппаратная/системная кнопка «Назад» сначала закрывает полноэкранное видео, затем экран плеера.

Это установка файла напрямую, не публикация в Google Play. Поведение разрешений зависит от версии Android и производителя телефона. При сообщении Play Protect следуйте его проверке; не отключайте защиту телефона целиком.

## 4. Установить на Android TV

1. Скопируйте `FamilyCinema.apk` на USB-флешку.
2. Подключите флешку к телевизору или приставке.
3. В уже установленном файловом менеджере откройте флешку и выберите файл. Если файлового менеджера нет, установите подходящий бесплатный менеджер из Google Play на телевизоре; наличие и цена приложений магазина зависят от региона.
4. Разрешите установку этому файловому менеджеру, если телевизор её запросит. Затем выберите **«Установить»**.
5. Откройте список приложений телевизора → **Family Cinema**.
6. Стрелками пульта выбирайте кнопки и карточки, **OK** открывает выбранное, **Back / Назад** возвращает назад.
7. Проверьте несколько фильмов. Управление внутри внешнего плеера зависит от самого сайта: если кнопки не реагируют на пульт, попробуйте другой плеер. В некоторых плеерах потребуется мышь или режим мыши на пульте.

APK один для телефона и Android TV. Из базы Lampa сохранены оба пункта запуска. На очень старом устройстве может не работать современный веб-плеер или HTTPS: наличие поддержки старого Android у оболочки не гарантирует поддержку видеосайта.

## 5. Если Lampa у вас уже установлена

1. Откройте Lampa.
2. Откройте **«Настройки»** (шестерёнка).
3. Выберите **«Расширения»**. В некоторых версиях этот пункт называется **«Плагины»**.
4. Нажмите **«Добавить плагин»**.
5. Скопируйте и вставьте целиком, одной строкой:

```text
https://jeavnex.github.io/ex-fs-lampa/family_exfs_plugin.js
```

6. Подтвердите добавление. Если Lampa спрашивает, разрешать ли запуск этого расширения, подтвердите только для указанного адреса вашего репозитория.
7. Полностью закройте Lampa и откройте снова.
8. В левом меню нажмите **«Семейный кинотеатр»**.

Если плагин пишет, что сервер не настроен, откройте в семейном интерфейсе **«Настройки API»** и вставьте:

```text
https://family-cinema-api.pvde.workers.dev
```

Подтвердите ввод. Должно появиться сообщение **«Сервер подключён»**. На других Android-сборках Lampa, где нет нашего отдельного экрана плеера, используется окно внутри веб-интерфейса или внешний браузер.

## 6. Что относится только к новому проекту Cloudflare

В аккаунте `78b2e8eb9b4aa24ca9f8e6c6ae79c9d3` используются:

| Что | Точное значение |
|---|---|
| Новый Worker | `family-cinema-api` |
| Его адрес | `https://family-cinema-api.pvde.workers.dev` |
| Новая D1 | `family_cinema_db` |
| ID новой D1 | `dcc2f29e-5453-48cc-b617-e499e7bc8586` |
| Имя привязки в Worker | `FAMILY_DB` |
| Таблица кэша | `movie_cache` |

Существующий проект `pruefung-vorbereitung` и его база не используются этим кодом. В конфигурации нет маршрутов вашего старого сайта, его доменов или его базы. `npm run deploy` и `npm run db:remote` проверяют точные имена и ID перед выполнением.

**Однако квоты бесплатного тарифа общие для аккаунта.** Отдельная база не даёт отдельного бесплатного лимита. Если один проект исчерпает общую квоту, это может временно затронуть другие проекты того же аккаунта. Абсолютную изоляцию квот внутри одного аккаунта обещать нельзя.

Не подключайте платный Workers Paid. По опубликованным тарифам на дату подготовки: Workers Free — 100 000 запросов в день и 10 мс процессорного времени на запрос; D1 Free — 5 млн прочитанных строк и 100 000 записанных строк в день, до 500 МБ в одной базе и 5 ГБ всего. Дневные квоты D1 учитываются по UTC. Бесплатные лимиты нужно проверять для всего аккаунта, включая старый проект.

Сервер сохраняет до 2000 записей, использует кэш Cloudflare и D1, не запускает обход всего сайта и не передаёт видео. Активность открытого API всё равно расходует общие квоты; это публичный адрес, а не секретный семейный сервер.

## 7. Проверить сервер и базу в Cloudflare

1. Откройте **https://dash.cloudflare.com/** и войдите в нужный аккаунт.
2. Слева нажмите **Storage & databases** → **D1 SQLite Database**.
3. Нажмите только **family_cinema_db**. Не открывайте настройки старой базы для этих действий.
4. Откройте вкладку **Console**.
5. Для проверки вставьте и выполните кнопкой **Execute**:

```sql
SELECT cache_key, updated_at, expires_at FROM movie_cache LIMIT 10;
```

6. После обращения к каталогу должны появиться строки кэша. `SELECT` только читает данные.
7. Слева нажмите **Compute** → **Workers & Pages** → **family-cinema-api**.
8. Откройте настройки привязок **Bindings** или ссылку **Add a binding**. В списке должна быть D1: имя **FAMILY_DB**, база **family_cinema_db**.
9. Откройте **https://family-cinema-api.pvde.workers.dev/health**. Нормальный ответ содержит `"ok":true`.

## 8. Повторно опубликовать сервер

Если официальный Wrangler уже авторизован на компьютере, достаточно открыть папку проекта в терминале и выполнить команды ниже. Если не умеете открывать терминал: в Проводнике откройте папку `backend-cf`, щёлкните пустое место правой кнопкой → **«Открыть в терминале»**.

```powershell
npm ci
npx wrangler login --scopes account:read workers:write workers_scripts:write d1:write
npm run deploy
```

Страница входа Wrangler запрашивает права к Workers и D1 всего аккаунта. Подтверждайте доступ самостоятельно, только если согласны. Авторизация хранится локально в официальном хранилище Wrangler; не отправляйте токен в чат и не добавляйте его в репозиторий.

Если D1 создана заново и таблицы ещё нет, `npm run db:remote` создаст только таблицу кэша в указанной новой базе. При изменившемся ID старые защитные проверки специально остановят команду: не отключайте их наугад, попросите помощника проверить именно новую базу.

Альтернатива без Wrangler: в Cloudflare выберите **Compute → Workers & Pages → family-cinema-api → Edit code**, замените содержимое главного файла полным содержимым `backend-cf/src/index.js` из GitHub и нажмите **Deploy**. Затем добавьте D1-привязку **FAMILY_DB → family_cinema_db**, если её нет. Для исходного Worker-шаблона имя файла может быть `worker.js`; весь модуль можно вставить в этот файл.

## 9. Повторно опубликовать сайт

1. Под аккаунтом владельца **jeavnex** откройте **https://github.com/jeavnex/ex-fs-lampa/settings/pages**.
2. В разделе **Build and deployment** у поля **Source** выберите **GitHub Actions**. Если уже выбрано, ничего не меняйте.
3. Откройте **https://github.com/jeavnex/ex-fs-lampa/actions/workflows/deploy-pages.yml**.
4. Нажмите **Run workflow** → зелёную **Run workflow**.
5. Дождитесь зелёной галочки. После публикации обновление страницы может занять некоторое время.

Последующие изменения файлов `plugin-web/` автоматически запускают публикацию. Workflow берёт этот каталог, добавляет закреплённый веб-клиент Lampa и помещает файл плагина прямо в корень сайта: адрес не содержит `plugin-web/`.

## 10. Обновления APK и постоянная подпись

**В вашем репозитории постоянная подпись уже настроена.** Итоговый `FamilyCinema.apk` собран с вашим отдельным закрытым ключом. Будущие сборки с этим же ключом можно устанавливать поверх предыдущих с сохранением данных. Не удаляйте и не меняйте секреты подписи без необходимости.

Самая первая проверочная сборка использовала отладочную подпись. Если вы успели установить именно её, перед первой установкой итогового подписанного APK Android может потребовать удалить тестовое приложение. Удалять стандартную Lampa не нужно — у Family Cinema другой идентификатор приложения.

Для регулярных обновлений с сохранением избранного нужен один постоянный закрытый ключ подписи. Workflow уже поддерживает его через четыре GitHub Secrets:

| Имя секрета | Содержимое |
|---|---|
| `FAMILY_KEYSTORE_BASE64` | Файл личного ключа JKS, преобразованный в Base64 |
| `FAMILY_KEYSTORE_PASSWORD` | Пароль хранилища ключа |
| `FAMILY_KEY_ALIAS` | Имя ключа в хранилище |
| `FAMILY_KEY_PASSWORD` | Пароль самого ключа |

Все четыре секрета уже добавлены в зашифрованном виде. GitHub не показывает их исходные значения. Локальная резервная копия ключа сохранена на компьютере, где выполнялась подготовка; она не находится в открытом репозитории или архиве исходников. Не публикуйте JKS, его Base64 или файл с паролями.

При восстановлении проекта: откройте репозиторий → **Settings** → **Secrets and variables** → **Actions** → **New repository secret**, введите соответствующее имя и значение из своей резервной копии и нажмите **Add secret**. В штатном использовании повторять это не нужно.

Без этих секретов workflow полностью собирает тестовый APK; с ними — подписанный APK для обновлений. Наличие секретов не публикует приложение в магазинах.

## 11. Если что-то не работает

| Что видно | Что сделать |
|---|---|
| Сайт GitHub Pages отвечает 404 | Проверьте шаг 9 и зелёный статус публикации |
| Ответ `/health` сообщает, что нет FAMILY_DB | Привяжите только новую D1 согласно шагу 7 |
| Ответ сообщает о таблице/schema.sql | Проверьте выполнение `backend-cf/schema.sql` только в новой базе |
| Каталог сообщает, что EX-FS недоступен | Откройте `https://ex-fs.net/` в браузере. Возможны блокировка или изменение сайта; повторите позже |
| Показана сохранённая копия | Источник временно недоступен. Список работает из кэша, ссылки плееров могут устареть |
| Фильм открывается, а видео — нет | Попробуйте другой плеер; сравните с оригинальной страницей EX-FS. Некоторые плееры запрещают чужое встраивание |
| Actions красный | Откройте запуск и первый красный шаг. Передайте помощнику ссылку на запуск, без паролей и ключей |
| APK не обновляется поверх старого | Разные ключи подписи; см. шаг 10 |
| На телевизоре нет иконки | Проверьте, что это Android TV/Google TV, а не Tizen/webOS; устанавливайте APK только на Android |

EX-FS — внешний источник. Код не обходит его ограничения и не гарантирует неизменность сайта, наличие каждого фильма или отсутствие рекламы. Пользуйтесь только материалами, доступными вам на законных основаниях. Возрастные ограничения выбирайте сами: автоматического детского фильтра здесь нет.
